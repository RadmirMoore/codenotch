# Codenotch для Codex: живые лимиты и оригинальный виджет

Персональная сборка для macOS 15+, основанная на [vinzdg/codenotch](https://github.com/vinzdg/codenotch), commit `00833690311067354c77951fcaaf6ffca774916e`. Оригинальные панели, наведение, перенос между краями, анимации, кольца и карточки лимитов сохранены. Подключение и настройки упрощены до Codex.

Это **остаток лимита аккаунта**, а не сумма токенов из локальных журналов. Под кольцом показывается оставшийся процент короткого/недельного окна. Предупреждающий цвет зависит от израсходованной доли. При наведении видны расход, остаток и сбросы. Время сброса берётся из ответа сервера, автоматически обнулять процент по местным часам приложение не пытается.

## Подключение

1. Войдите в официальный Codex через ChatGPT.
2. Запустите `Codenotch Local.app`, нажмите **Подключить Codex…**.
3. В диалоге выбора нажмите **⌘⇧G**, введите `~/.codex/auth.json` и выберите файл. При другом CODEX_HOME выберите его `auth.json`.
4. Закройте настройки: виджет остаётся у правого края. Наведите указатель для раскрытия. Перетащите ручку перемещения к другому краю; ⌥ + перетаскивание перемещает вдоль края. Край также выбирается в настройках.
5. Повторное открытие приложения или значок Codex в строке меню открывает настройки.

Опрос сервера — каждые **30 секунд**, ручные попытки не чаще чем раз в 10 секунд. Это периодическое получение серверных данных, не push-поток; сервер может обновлять данные с задержкой. HTTP 429 учитывает Retry-After, в том числе после перезапуска. При ошибке предыдущий результат немедленно помечается устаревшим. При 401/403 нужно обновить вход в официальном Codex. Никаких команд входа или обновления токенов эта сборка не запускает.

## Граница доступа

- Подписанный ad-hoc App Sandbox: только исходящий Интернет, выбранный файл только для чтения и bookmark для повторного доступа. Sandbox сам по себе не фильтрует домены; точные адреса ограничены в коде сетевого клиента.
- Разрешены только GET `https://chatgpt.com/backend-api/wham/usage` и `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits`. Второй адрес читает доступные сбросы, **не выполняет сброс**.
- Серверу передаются только `access_token` и идентификатор аккаунта. Это полноценный токен сессии, не отдельный узкий ключ для статистики. Он нужен для аутентификации сервером Codex. Сборка не копирует его в настройки, логи, Keychain или свой файл.
- Все HTTP-перенаправления отклоняются. Стандартная системная проверка TLS, без обходов. Эфемерная URLSession без cookie-хранилища, кэша и сохранения HTTP credentials; ответы ограничены 2 МиБ.
- Файл авторизации не изменяется, перечитывается при каждом опросе для смены токена самим Codex. Символическая ссылка вместо файла и файлы больше 1 МиБ отклоняются.
- Не читаются переписки, rollouts, базы чатов и ключи других провайдеров. Не запускаются команды оболочки. Геометрия экранов/окон используется оригинальным виджетом для размещения, содержимое окон не считывается.
- Нет Sparkle, проверок версий, загрузки обновлений, телеметрии, сторонних зависимостей, локального сервера и интеграции с телефоном. Установка новой версии — только вручную.
- Старые локальные результаты не сохраняются между запусками. Сохраняются настройки виджета, bookmark выбранного файла и время ограничения частоты запросов.

Отсутствие обнаруженной утечки не является гарантией абсолютной безопасности. Адреса `/backend-api/wham/` использует оригинальный проект; это внутренний интерфейс Codex, он может измениться.

## Сборка и проверка

Нужен Xcode 26+ (как для оригинальных Liquid Glass компонентов), Swift и Python 3. Скачивать пакеты сборке не требуется.

```sh
make test
make build
```

Готовый пакет: `build/Codenotch Local.app`. Закройте запущенное приложение перед заменой. `make verify` проверяет подпись, entitlements, отсутствие обновлятора и сторонних библиотек, а также единственный сетевой модуль. Это дополнительные автоматические проверки, не формальное доказательство безопасности.

Тесты используют искусственные данные; реальные credentials и сеть для них не нужны. LICENSE исходного проекта сохранён. Основной UI взят из upstream; адаптер сети, подключение выбранного файла и узкие настройки этой сборки переработаны.
