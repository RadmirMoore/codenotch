# Codenotch Local — только локальные токены Codex

Минимальная macOS-версия форка [Codenotch](https://github.com/vinzdg/codenotch).
Вместо множества интеграций — небольшое приложение с окном и счётчиком в строке меню, считающее
токены из локальных журналов Codex. Без подключения аккаунтов, интернета,
автообновлений, телеметрии и сторонних библиотек. macOS 13 или новее.

Это отдельное приложение `Codenotch Local` с идентификатором
`io.github.radmirmoore.codenotch.local`. Старый Codenotch оно не заменяет,
не обновляет и не запускает. Если старый Codenotch уже установлен, закрой его
и отключи его запуск при входе отдельно: настройки новой версии на него не влияют.

## Что показывает

- Токены за сегодня, последние семь календарных дней (включая сегодня) и всё
  время, представленное в выбранных журналах. Периоды — в часовом поясе Mac.
- Входящие и исходящие токены; отдельно входящие из кэша и исходящие рассуждений.
  Кэш уже включён во входящие, рассуждения — в исходящие: второй раз их не суммируем.
- Проверка новых записей каждые 15 секунд. Большая история читается порциями;
  пока она не дочитана, интерфейс явно показывает промежуточный результат.

Источник: записи `event_msg` → `token_count` → `info.total_token_usage` в
`rollout-*.jsonl`. Учитывается **разница накопительных счётчиков**, а не сумма
всех снимков. Повторные записи без прироста не добавляют токены. Копии записей
в архиве и скопированные префиксы форков дедуплицируются по времени записи и
накопительным числам. Независимые события с полностью одинаковыми временем
и числами неотличимы от копий: это ограничение дедупликации.

Это **не остаток лимита подписки**, не биллинг и не точный счёт за API.
Не видны облачные сессии, которые не записывают локальные token_count,
удалённые журналы и неподдерживаемые форматы. При добавлении папки с неполной
историей первый накопительный снимок целиком относится ко времени этой записи.
При уменьшении накопительных счётчиков начинается новый сегмент и появляется
предупреждение; по одному журналу нельзя надёжно отличить сброс от исправления
ранее записанной статистики. Удаление журнала убирает его токены из результата.

## Ограничения безопасности

- Подписанная сборка использует **App Sandbox**. Нет разрешений network.client,
  network.server, Apple Events, исключений sandbox или get-task-allow.
- Чтение только папок `sessions` и `archived_sessions`, явно выбранных через
  системный диалог. Не выбирай целиком `.codex`: приложение отвергнет такую папку.
- Разрешения на папки сохраняются как security-scoped bookmarks с доступом
  только на чтение. «Забыть папки» удаляет bookmarks и статистику из памяти.
- Нет чтения `auth.json`, связки ключей, SQLite-каталогов других приложений,
  cookie-хранилищ, переменных с API-ключами или поиска дополнительных аккаунтов.
- Журналы **содержат тексты переписок**, поэтому их байты проходят через
  потоковый парсер. Приложение извлекает только время и счётчики; тексты,
  команды, пути проектов и данные аккаунтов не сохраняет и не журналирует.
- Ссылки на файлы/каталоги и файлы с несколькими жёсткими ссылками пропускаются.
  Открытие через `openat` с `O_NOFOLLOW` проверяет каждый компонент пути.
- Длина одной строки ограничена 1 МиБ. Слишком длинные строки пропускаются;
  интерфейс сообщает о пропусках. Частичные строки ждут следующей записи.
- Все числа хранятся только в оперативной памяти. На диске сохраняются только
  выбранные разрешения в собственном контейнере приложения.
- Нет внешних Swift-пакетов, механизмов обновления, загрузки кода, автозапуска,
  установочных hooks, серверов или запуска дочерних программ.

Sandbox ограничивает случайный доступ и последствия ошибок, но не делает
непроверенные будущие изменения безопасными. Выбирай только собственные журналы;
перед ручной сборкой новой версии проверяй diff, особенно entitlements и сборку.

## Сборка и установка из своего форка

Нужен установленный Xcode с инструментами Swift. Homebrew, npm, Rust,
XcodeGen, Sparkle и дополнительные пакеты не нужны.

```sh
git clone --branch harden/codex-local-only https://github.com/RadmirMoore/codenotch.git
cd codenotch
make test
make build
```

Результат: `build/Codenotch Local.app`. Сборка подписана локальной ad-hoc
подписью с hardened runtime и sandbox; это не Developer ID и не нотариализация
Apple. `make build` проверяет подпись, **фактические entitlements в сборке**,
отсутствие зависимостей, метаданных обновлений и некоторых запрещённых API.
Эта автоматическая проверка дополняет, но не заменяет аудит исходников.

Перетащи приложение в свою папку Applications или выполни:

```sh
make install
```

Устанавливает в `~/Applications` без sudo и **не запускает** приложение.
Существующую установку не перезаписывает. Запусти вручную через Finder:
откроется окно счётчика, в Dock появится значок, а в строке меню — `Codex —`.
После закрытия окна приложение продолжает работать. Повторное открытие через
Finder, ярлык или Dock снова показывает окно. Полностью закрыть — кнопкой «Выход».

1. Нажми «Добавить папку…».
2. В системном диалоге нажми **⌘⇧G**, введи `~/.codex/sessions` и подтверди.
3. При необходимости отдельно добавь `~/.codex/archived_sessions`, если она существует.
4. Для другого профиля вручную выбери его папку `sessions`. Автоматического поиска нет.

Обновлений приложение не ищет. Новая версия устанавливается только вручную:
проверка изменений, тесты, сборка, **выход из запущенной версии** и замена `.app`.
Замена файла сама по себе не завершает старый процесс: если он остался без окна,
заверши именно Codenotch Local через «Мониторинг системы», затем открой приложение снова.
После изменения локальной подписи macOS может попросить выбрать папки снова.
Команд для снятия карантина или ослабления связки ключей здесь нет.

## Разработка и происхождение

`Sources/TokenCounter` — потоковый парсер и счётчик; `Sources/CodenotchLocal` —
интерфейс и выдаваемые пользователем разрешения. Тесты используют временные
синтетические журналы и не читают реальные данные Codex.

Форк переработан на основе upstream-коммита
`00833690311067354c77951fcaaf6ffca774916e`. Старые интеграции, Windows-порт,
исходники обновления, готовый DMG и workflows публикации удалены из этой ветки;
история Git и лицензия MIT сохранены. Поддержка Windows в этой минимальной версии отсутствует.
